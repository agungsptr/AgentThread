# `agt stop` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** `agt stop` shuts down the daemon, every thread and workers tab, the logger pane, the workspace stack and the main manager, keeping thread state for the next `agt start`.

**Architecture:** A pure planner (`stopTargets`) and an orchestrator (`runStop`) with injected side effects live in `src/cli/stop.ts`; `main.ts` wires the real daemon socket, `HerdrCli`, `stackServices` and a pid-file based main-manager stop. `agt start` writes `.agentthread/main.pid`.

**Tech Stack:** Bun + TypeScript, `bun test`, `tsc --noEmit`.

**Spec:** `docs/superpowers/specs/2026-11-27-agt-stop-design.md`

## Global Constraints

- Order: refuse agent panes → read state → stop daemon → close tabs → close logger → stop stack → stop main.
- Refusal message: `agt stop runs from your own shell or the main manager, not a coordinator or worker pane`.
- Pid file: `.agentthread/main.pid` (`paths(root).dir`), the main agent process's pid, removed when `agt start`'s agent exits.
- Full-suite verification: `bun run typecheck && bun test --timeout 20000`.

## Review Focus

1. **Daemon not running** (crashed, or already stopped): state is read from `state.db`; tabs, logger, stack and main still stop. Test in Task 1 (fake) and Task 3 (CLI).
2. **A tab already closed by hand**: skipped, not an error. Test in Task 1.
3. **Stale `main.pid`** (pid dead or recycled to another program): ignored, never signalled. Test in Task 2.
4. **No Herdr layout registered** (agt never started in Herdr): only daemon, stack and main steps run. Test in Task 1.
5. **Main runs `agt stop` itself**: main is signalled last, after every other step printed. Test in Task 1 (order).

### Task 1: `stopTargets` and `runStop`

**Files:** Create `src/cli/stop.ts`; Test `tests/cli/stop.test.ts`

**Interfaces (produces):**
- `stopTargets(state: State, tabs: { tabId: string; label: string }[]): { tabs: string[]; loggerPane?: string }` — every existing tab that is a thread's `tab` or one of its workers tabs (`workersTabOrder(label, \`${t.id}-${t.slug}-workers\`)`), never `layout.mainTab`; `loggerPane` from the layout.
- `runStop(d: StopDeps): Promise<{ code: number; lines: string[] }>` with
  `StopDeps = { readState(): Promise<State>; daemonAlive(): Promise<boolean>; stopDaemon(): Promise<void>; herdr(layout: Layout): { tabList(ws: string): { tabId: string; label: string }[]; closeTab(id: string): void; paneExists(p: string): boolean; closePane(p: string): void }; stopStack(): Promise<string[]>; stopMain(): string | undefined }`.

- [ ] Tests (fakes record calls in order): full run → calls `stopDaemon, closeTab×n, closePane(logger), stopStack, stopMain` in that order and lines `daemon stopped`, `closed 2 thread tabs`, `logger pane closed`, stack lines, `main manager stopped`; daemon down → `daemon not running`, rest still runs; no layout → no Herdr calls, line `no Herdr layout`; a tab missing from `tabList` is not closed; a Herdr throw → line `herdr: <msg>`, code 1, stack and main still run.
- [ ] Run → FAIL; implement; run → PASS; commit `feat: agt stop shuts down threads, logger, stack, daemon and main in order`.

### Task 2: main manager pid file and `stopMainManager`

**Files:** Modify `src/cli/main.ts` (`start`); add to `src/cli/stop.ts`; Test `tests/cli/stop.test.ts`

**Interfaces (produces):** `mainPidFile(root: string): string`; `stopMainManager(root: string, kill?: (pid: number, sig: string) => void): string | undefined` → `"main manager stopped"` | `undefined` (no file, dead pid, or command line without the agent) — removes the file in every case it reads one.

- [ ] Tests: a live `sleep 30` child whose pid is in the file, with the expected command check → SIGTERM sent, returns the line, file gone; a dead pid → undefined, file gone, nothing signalled; no file → undefined.
- [ ] `start`: write the pid after `Bun.spawn`, remove it after `proc.exited` (also on the catch path).
- [ ] Run → FAIL; implement; run → PASS; commit `feat: agt start records the main manager's pid for agt stop`.
